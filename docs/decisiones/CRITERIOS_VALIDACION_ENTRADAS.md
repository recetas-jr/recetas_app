Validaciones obligatorias del sistema
Selección de receta

El ID debe existir.

No se aceptan valores no numéricos.

Raciones solicitadas

Debe ser número entero.

Debe ser mayor que cero.

Comportamiento ante error

El sistema no debe finalizar abruptamente.

Debe solicitar nuevamente el dato.
