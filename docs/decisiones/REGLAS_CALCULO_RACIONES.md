Regla matemática oficial
Fórmula
cantidad_ajustada =
(cantidad_base / raciones_base) * raciones_objetivo

Reglas asociadas

Todas las unidades se conservan.

No se realizan conversiones de unidades.

El resultado se redondea solo para presentación.

El valor base nunca se altera.

Motivo

La proporción simple garantiza consistencia y escalabilidad.
